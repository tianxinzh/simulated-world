免费在线微缩机场模拟器 — BAYPORT

在橡木桌上的湾区风格机场沙盘中观看起飞、降落和地面交通，操作六个实体控件，无需安装即可免费探索。

点击开始后加载互动场景，无需注册或安装。

直接打开独立场景 · 下载单文件 HTML · 需要 WebGL 与加载 Three.js 的网络连接。

可以怎么玩？

BAYPORT 是互动机场沙盘，而非驾驶舱飞行模拟器。飞机沿预设路线运行，你可以调节节奏、灯光及部分机场操作。无需积分、付费或账户即可探索。

从桌子前沿开始，拖动空白区域环视，滚轮缩放。尝试操作实体控制台，再切换到夜晚欣赏微缩灯光。按 0 返回初始视角。

这是真实的旧金山机场吗？

不是。地理、基础设施和距离经过艺术化压缩以适配桌面。这不是导航地图或专业操作训练工具。

可以在本地运行吗？

可以。下载单文件 HTML 并用 Chrome 打开。仍需网络加载 Three.js，模型、材质与合成声音由文件内代码生成，下载版不包含统计标签。

画面空白怎么办？

请允许 JavaScript 与 WebGL，检查硬件加速及 Three.js CDN 的网络连接。停止播放器后再重试。窄屏下可使用全屏，让实体控件有更多空间。
