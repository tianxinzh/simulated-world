# Launch kit

These are drafts and proposed experiments. Nothing has been posted to any social account, mailing list or community on the owner's behalf. Check each community's current rules before posting and disclose the AI-assisted development workflow honestly.

## Product description

Simulated World is a collection of free, browser-based interactive miniature worlds. BAYPORT is a Bay Area-inspired airport diorama; BAYLINE is a San Francisco-inspired model railway. Operate the physical tabletop controls and watch a day-night cycle. These are artistic model layouts, not cockpit simulators or professional operational-training tools.

## Developer post draft

BAYPORT and BAYLINE are single-HTML Three.js miniatures using procedural geometry, CanvasTexture labels/wood grain, instanced repeated elements and preplanned movement paths. The website wraps those scenes with searchable guides and a same-origin message bridge for consent-gated engagement events. The downloaded worlds have no analytics tag. A write-up of the rendering and controls is at /guides/how-built/. This is an AI-assisted build; current limitations include artistic rather than physical scale and device-dependent WebGL performance.

## First four weekly experiments

1. Foundation: connect Search Console/GA4/Bing, verify sitemap, check real events. Do not announce tracking as active until Realtime confirms it.
2. Content: check queries for the two world pages and their controls guides. Improve actual user questions rather than create near-duplicate keyword pages.
3. Distribution: publish three distinctly tagged clips/posts where appropriate. Compare successful loads and engaged play instances by source.
4. Iteration: investigate mobile errors and low readiness first; then compare the strongest channel and repeat one improved creative.
