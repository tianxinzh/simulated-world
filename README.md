# Simulated World

Open-source components and selected demos from **Simulated World** — a collection of interactive browser-based miniature worlds inspired by airports, railways, cities, ports, and infrastructure.

## Project split

- **This repository**: reusable Three.js/voxel components, selected simulator demos, documentation, and examples.
- **Production website**: maintained separately in a private repository for SEO, analytics, monetization, and unreleased worlds.

## Planned first demos

- San Francisco Bay Airport
- San Francisco Model Railway

## Stack

- Vanilla HTML/CSS/JavaScript
- Three.js
- Procedural geometry/materials
- No external visual assets in simulator builds unless explicitly documented
